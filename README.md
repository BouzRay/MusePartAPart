# MusePartAPart — アース観察シミュレーション

Seed 値で管理される世界「アース」を、プレイヤーが完全観察で眺める自律シミュレーションゲームのプロジェクトです。

## 概要

- 各アースには住人が 100 人いる
- 住人は HP / MP のようなゲーム的パラメータではなく、健康や身体的特徴（身長・体重など）と性格（執着、飽きやすさ、共感性、情動感受性、直感志向、社交性、攻撃性、保守性、楽観性、探求心、協調性、利益志向、危険許容度、計画性）で管理される
- 住人は AI 的に自律行動し、街（店・鍛冶屋・大工屋）や森林、洞窟、ダンジョン、火山などの場所で活動しながらアースを発展させていく
- プレイヤーは介入しない。ログとランキングを観察して楽しむ
- 1 つのアースは住人が全滅したら終了する。シーズンは参加アースがすべて全滅するまで終わらない
- 時間は 1 日 = 5 秒で進み、アプリを閉じても裏で進み続ける
- シーズンごとに、どの Seed のアースが一番長く続いたか、どんな文明や新しいアイテムを見つけたかを競う
- 競う相手は最初は自分のアース同士。将来的にオンライン化する
- Seed はランダム配布と手入力の両方に対応する
- 初期住人 100 人は、家族ではなく完全にランダムな個人として生成される

世界観はファンタジー寄り。

## ステータス

MVP プロトタイプ実装中（sim v0.5.0）。MVP の規模は 20 人で開始することが決まった。設計は 100 人のまま、初期人口は設定値で切り替える。場所は街・森林・鉱山・洞窟・ダンジョンの 5 か所。

v0.2.0 で資源に使い道が付いた：道具は採取・採掘の効率を上げ、採掘・探索の怪我を減らす（たまに壊れる）。木材と鉱石は建築にも使われ、建物（木の柵・住居・倉庫・鍛冶場・集会所・診療所、完成後は住居の増築）がそれぞれ街に効果を与える。

v0.3.0 で図書館を追加した。町の発展や発見は、歴史書・文献・知識の本によって進んでいく設計とし、図書館はその核になる建物。現時点では「知識の蓄積で発見確率が上がる」という土台効果のみで、最初に置く本はこれから決める。

v0.4.0 で本と知識の仕組みを入れた。知識の基本原則：住人は最初は知識を持たず、全ての知識は図書館から得る。図書館は建築順の 3 番目に移り（木の柵・住居までは知識なしで建てられる）、蔵書は鍛冶・採掘・伐採・大工・調剤の 5 冊。住人は「学ぶ」行動で適性のある本を読み、知識を習得する。採掘・鍛冶・調剤と、図書館より後の建築には対応する知識が必要で、伐採の知識は採取の木材収量を上げる。調剤は薬草から薬を作り、看病で使う。住人が自主的に店員になる仕組みは次の段階。

v0.5.0 で場所を 5 か所に拡張した：街・森林・鉱山・洞窟・ダンジョン。伐採は森林で行う独立した行動になり（伐採の知識が必要、木材の本格生産）、採掘は洞窟から鉱山へ移った。探索の行き先は森林（低リスク・低発見）／洞窟（中リスク）／ダンジョン（高リスク・高発見）で、危険許容度が高い住人ほどダンジョンに行きやすい。洞窟は探索専用の場所になった。

- `src/EarthSim.Core` — ヘッドレスな C# シミュレーションエンジン（UI に依存しない）
- `src/EarthSim.Console` — コンソール UI（テキストログ観察用）
- `tests/EarthSim.Core.Tests` — 決定論テスト（同じ Seed = 同じ結果）

実行例:

```bash
dotnet run --project src/EarthSim.Console -- --seed 12345 --population 20
```
