# MusePartAPart — アース観察シミュレーション

Seed 値で管理される世界「アース」を、プレイヤーが完全観察で眺める自律シミュレーションゲームのプロジェクトです。

## 概要

- 各アースには住人が 100 人いる
- 住人は HP / MP のようなゲーム的パラメータではなく、健康や身体的特徴（身長・体重など）と性格（執着、飽きやすさ、共感性、情動感受性、直感志向、社交性、攻撃性、保守性、楽観性、探求心、協調性、利益志向、危険許容度、計画性）で管理される
- 住人は AI 的に自律行動し、街（店・鍛冶屋・大工屋）や森林、洞窟、ダンジョン、火山などの場所で活動しながらアースを発展させていく
- プレイヤーは介入しない。ログとランキングを観察して楽しむ
- 1 つのアースは住人が全滅したら終了する。シーズンは参加アースがすべて全滅するまで終わらない
- 時間は 1 日 = 5 秒で進み、アプリを閉じても裏で進み続ける
- シーズンごとに、どの Seed のアースが一番長く続いたか、どんな文明や新しいアイテムを見つけたかを競う
- 競う相手は最初は自分のアース同士。将来的にオンライン化する
- Seed はランダム配布と手入力の両方に対応する
- 初期住人 100 人は、家族ではなく完全にランダムな個人として生成される

世界観はファンタジー寄り。

## ステータス

MVP プロトタイプ実装中（sim v0.1.0）。MVP の規模は 20 人／場所 3 か所（街・森林・洞窟）で開始することが決まった。設計は 100 人のまま、初期人口は設定値で切り替える。

- `src/EarthSim.Core` — ヘッドレスな C# シミュレーションエンジン（UI に依存しない）
- `src/EarthSim.Console` — コンソール UI（テキストログ観察用）
- `tests/EarthSim.Core.Tests` — 決定論テスト（同じ Seed = 同じ結果）

実行例:

```bash
dotnet run --project src/EarthSim.Console -- --seed 12345 --population 20
```
